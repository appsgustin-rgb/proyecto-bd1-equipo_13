# Alcance del sistema

El sistema estará orientado a la gestión de ventas y distribución de productos de una distribuidora de agua y soda envasada.

## Funcionalidades incluidas

El sistema permitirá:

- Registrar, modificar, eliminar y consultar clientes.
- Registrar y administrar productos.
- Clasificar productos mediante categorías.
- Registrar proveedores.
- Asociar proveedores con los productos que suministran.
- Registrar ventas realizadas a clientes.
- Registrar los productos incluidos en cada venta.
- Almacenar la cantidad vendida de cada producto.
- Conservar el precio histórico de cada producto al momento de la venta.
- Administrar métodos de pago.
- Mantener actualizado el stock de productos.
- Registrar repartidores.
- Registrar entregas asociadas a ventas.
- Asignar repartidores a las entregas.
- Registrar el estado de las entregas.
- Consultar ventas, clientes, productos, stock y entregas.

## Fuera del alcance

En esta primera versión del sistema no se contempla:

- La gestión contable completa de la empresa.
- El cálculo de sueldos de empleados.
- La gestión de mantenimiento de vehículos.
- La gestión de maquinaria utilizada en la producción.
- La facturación electrónica ante organismos fiscales.
- La administración de rutas de reparto mediante geolocalización.
