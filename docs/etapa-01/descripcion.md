# Descripción del caso

## Sistema Gestor de Ventas - Distribuidora de Agua y Soda Envasada

El rubro seleccionado corresponde a una distribuidora de agua y soda envasada.

Este tipo de empresa se dedica a la producción, comercialización y distribución de productos como agua, soda, bidones y otras bebidas. Para realizar sus actividades cuenta con maquinaria específica, medios de transporte, personal e instalaciones.

El sistema propuesto tiene como objetivo gestionar las principales operaciones comerciales de la distribuidora, especialmente el registro de clientes, productos, ventas, métodos de pago, stock y entregas.

Además, se busca mantener un historial correcto de las ventas realizadas, conservar el precio de cada producto al momento de la operación y controlar las entregas efectuadas a los clientes.

El sistema será utilizado como soporte para organizar la información comercial de la distribuidora y facilitar futuras consultas e informes.
